# ProxyMaster Passwall2 Mini App

A simple, companion web UI for managing ProxyMaster and Passwall2 on OpenWrt.

## Quick Install

```bash
rm -f /tmp/install.sh && wget -O /tmp/install.sh https://raw.githubusercontent.com/sadraimam/proxymaster_passwall2/main/install.sh && chmod +x /tmp/install.sh && sh /tmp/install.sh
```
